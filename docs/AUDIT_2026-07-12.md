# worldlabs-mcp Audit — 2026-07-12

Scope: full repo assessment against AGENT_PROTOCOLS v1.34 (2026-07-11), WEBAPP_SOTA_STANDARDS v1.0, MCPB/Tauri build lanes. Verified live: 49/49 offline tests pass (8 live-skipped), `ruff check .` clean, `mcpb validate` passes on `mcpb/manifest.json`, both `dist/worldlabs-mcp-v0.5.0.mcpb` and NSIS `World Labs MCP_0.1.0_x64-setup.exe` exist (built 2026-06-23).

## Verdict

Strong repo. Test discipline, Prefab cards, worldlabs_help, llms.txt pair, security fixes already landed (Plex token, path traversal, shell=True), and a genuinely good Tauri sidecar spawner (pipe-deadlock fix, TCP health loop, kill-on-exit). The problems are drift, not rot: five different version numbers, a stale mcpb staging copy, a shadowed Vite config, and standards that moved under it this week.

## P1 — Bugs

1. **Version incoherence (5-way).** pyproject `0.4.0`; server.py FastMCP + FastAPI + mcpb manifest `0.5.0`; tauri.conf.json + Cargo.toml `0.1.0`; web package.json `0.2.1`; git tag `v1.0.0-sota`. `just version` reports pyproject → wrong. Fix: single-source from pyproject (importlib.metadata in server.py), bump all to 0.5.0, add a bump step to release flow.
2. **`just pack` / `just validate` broken.** Both run `mcpb pack` / `mcpb validate` from repo root, where no `manifest.json` exists. The real manifest lives in `mcpb/` staging. Also `scripts/mcpb-pack.ps1` uses `npx` (fleet standard: `bunx`).
3. **`mcpb/` staging drift.** `mcpb/src/worldlabs_mcp/server.py` hash ≠ `src/worldlabs_mcp/server.py`. Next pack ships stale code. Additionally `mcpb/src/*.py` contains loose duplicates alongside the package dir. Staging must be regenerated from `src/` on every pack, never hand-edited.
4. **`vite.config.js` shadows `vite.config.ts`.** Vite resolves `.js` before `.ts`; the tracked-and-currently-modified `.ts` (127.0.0.1 proxy target) is dead code. The two configs differ. Delete one (keep `.ts`, port the esbuild `.js`→jsx loader block if still needed).
5. **Stale transpiled `src/main.js` / `src/App.js` tracked in git** (May 23, CommonJS-with-JSX — non-runnable). Currently dead because `main.tsx` imports `./App.tsx` with explicit extension, but this is the exact bug class that broke the library page via `api.js`. Delete both.
6. **CHANGELOG corrupted.** An `## [Unreleased] — 2026-06-14` block sits above the `# Changelog` header; two Unreleased sections; compare-links stop at 0.3.0. No `CHANGELOG_LATEST.md` (fleet convention).
7. **CORS: `allow_origins=["*"]` + `allow_credentials=True`** on a bridge that launches Blender/Unity, runs adb, serves local files, and proxies arbitrary URLs. Starlette echoes the caller origin when credentials+wildcard, so any webpage open in a browser on Goliath can read responses from `127.0.0.1:10865`. Restrict to `http://localhost:10864`, `http://goliath:10864`, and the tauri origins.
8. **`GET /api/handoff?url=` is an open SSRF proxy.** Fetches and streams any URL server-side. Combined with (7): drive-by pages can use Goliath as a proxy or scan the Tailscale network. Allow-list Marble CDN hosts (and localhost avatar-mcp if needed).
9. **Silent `except Exception: pass`** on `MCP_BRIDGE_URLS` proxy registration in server.py — contra Implementation Honesty standard. Log at warning minimum.
10. **CI only fires on `v*` tags + manual dispatch** — no push/PR coverage. Plus `ci.yml.20260701_030123.bak` committed inside `.github/workflows/`.
